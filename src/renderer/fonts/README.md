# Roboto

Roboto is bundled locally for offline writing practice. The variable font
supports the normal weights used by the app. The app does not fetch fonts
at runtime.

Source: https://github.com/google/fonts/tree/main/ofl/roboto

Font: Roboto[wdth,wght].ttf, saved as Roboto-Variable.ttf.
License: SIL Open Font License 1.1, included in OFL-Roboto.txt.
